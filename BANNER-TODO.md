   `docs/assets/banner.svg?v=3.9` в том же формате, что и `README.md`
   (центрированный `<p align="center">`, тот же набор бейджей), и поправь дерево.
3. **Старый `docs/banner.png`** — удали (`git rm`), когда на него не останется

4. **Коммит** на ветке `docs/re-present-keel-style`. Сообщение — человеческим

## Конвенция на будущее
При каждом релизе, меняющем баннер: обнови версию в кикере SVG (`vX.Y`) **и**
хвост `?v=X.Y` в обоих README — тогда рендер на GitHub обновится сразу.
