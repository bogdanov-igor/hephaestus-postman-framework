hephaestus

Scattered scripts, forged into one engine.

A modular API-testing engine for Postman & Newman. Declare what a response should be; the engine handles assertions, structural snapshots, schema checks, a security audit, reports and CI gates.

// Declare what you expect — the engine does the rest
const override = {

  expectedStatus: 200,
  maxResponseTime: 1500,

  // Structural shape — one line per field
  assertShape: {
    "data.id":    "number",
    "data.email": "string",
    "data.roles": "array",
    "error":      "absent",
  },

  // Value assertions — combine operators
  assertions: {
    "data.status": { eq: "active" },
    "data.score":  { gte: 0, lte: 100 },
  },

  snapshot: { enabled: true, mode: "structural" },
  varsToSave: { token: { path: "data.token" } },
};

The engine

Everything a request needs, in one config block

The engine lives inside Postman as collection data and runs a fixed pipeline over every request. Each capability is opt-in and off by default — existing collections upgrade untouched.

15

Assertion operators

Value checks that combine per field — eq, gt, gte, matches, type, includes, absent, and more, with soft and when.

◇

Structural snapshots

Baselines keyed by request. strict, non-strict, or structural — the last compares shape only, so volatile ids and timestamps never register as drift.

{ }

Schema & shape

Full JSON Schema via a bundled tv4, plus one-line assertShape path→type checks and per-element assertEach rules.

🛡

Security audit

Passive response checks: cookie flags, alg:none / expired JWTs, missing no-store, insecure CORS. Each emits its own failing test.

⇄

GraphQL & retries

GraphQL answers 200 even with errors[] — graphql checks the real contract. retryOnStatus honours the server's Retry-After, capped.

ru

Bilingual output

Every test name, log line and error routes through a locale catalog. ru and en ship; both are byte-locked by a golden harness.

In practice

Read like a spec, run like a gate

override.js
// A 404 is the expected result — the run stays green
// because the test says so, not because nothing ran
const override = {
  expectedStatus: 404,
  assertions: {
    "error": { exists: true },
    "error.code": { eq: "NOT_FOUND" },
  },
};
# Every command exits non-zero on its own threshold
newman run api.json -r json --reporter-json-export run.json

hephaestus summary run.json --sla=800     # p95 > 800ms → exit 1
hephaestus compare base.json run.json    # regression → exit 1
hephaestus coverage --spec api.yaml \
                     collection.json --min 80  # under 80% → exit 1
# Green in 60 seconds — no account, no API key, no network
npx hephaestus init --demo

# terminal 1 — serve the recorded responses
hephaestus mock hephaestus-demo/demo-collection.json -p 4010

# terminal 2 — run against them
newman run hephaestus-demo/demo-collection.json \
  -e hephaestus-demo/demo-environment.json
# → 5 requests, 35 assertions, all green
